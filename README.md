# Ava-Jauncey-Dancing-With-Code-CC-A2
Creative Coding A2
My project, Dancing with Code is an EDM song made entirely through code. This project was a challenge for me due to my limited experience with Python and coding in general but through trial and error I had a lot of fun making it. Enjoy!

# 1. General Information

+ My project was both a learning challenge, and success for me, the "problem" it intends to solve is the lack of coded music within the EDM and Hyperpop genres. I undertook this project as I have a passion for music in my daily life, and I wanted to code something I knew would relate to my life. The purpose of my song was to make something upbeat, that I could enjoy on the way to uni.
